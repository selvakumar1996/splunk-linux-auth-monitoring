## 📂 SPL Queries

All queries are stored inside the `spl_queries` folder.

- failed_login.spl  
- brute_force.spl  
- successful_login.spl  

## 🚀 How To Run
1. Install Splunk Enterprise  
2. Add `/var/log/auth.log` as Data Input  
3. Restart Splunk  
4. Run SPL queries from `spl_queries` folder  
5. Create alerts and dashboards  

## 📸 Screenshots
Screenshots of detections, alerts, and dashboard are stored inside the `screenshots` folder.

Built a working SIEM solution for Linux authentication monitoring with real-time detection, alerting, and visualization.
